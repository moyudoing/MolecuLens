# 08 · 安装与发布（Windows）

本章说明如何安装 MolecuLens 的 Windows 发行版，以及维护者如何从源码重新打一个安装包。
面向使用者的操作与面向维护者的构建是两条独立路径，互不影响。

## 一、系统要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11，**64 位**（安装程序会拒绝 32 位系统） |
| 显卡 | 支持 Vulkan 1.2 的 GPU + 厂商最新驱动（NVIDIA / AMD / Intel 均可） |
| 磁盘 | 约 15 MB（安装后；示例数据可选） |
| 权限 | **不需要管理员权限**（按用户安装到 `%LOCALAPPDATA%\Programs\MolecuLens`） |
| 运行库 | 不需要单独安装 VC++ 运行库（安装包已 app-local 携带） |

> Vulkan 运行库 `vulkan-1.dll` 由显卡驱动提供。安装程序检测不到时只做提示，
> 不影响安装；但首次渲染前请先装好显卡驱动。

## 二、安装

1. 下载 `MolecuLens-<版本>-win64-Setup.exe`（建议用 `SHA256SUMS.txt` 校验）；
2. 双击运行，按向导选择组件：
   * **MolecuLens 主程序**（必需）——图形界面 + Vulkan 渲染引擎 + 字体 + 许可；
   * **命令行工具 moleculens-cli**——无头渲染 / 格式转换 / 结构信息；
   * **示例分子数据**——`EPI.pdb`、`md.gro` 等 9 个演示文件；
   * **开始菜单快捷方式** / **桌面快捷方式**。
3. 安装完成后可直接启动。首次启动是空场景，用「打开文件」或把结构文件拖进窗口即可。

静默安装（适合批量部署）：

```bat
MolecuLens-2.19.0-win64-Setup.exe /S
:: 指定目录（/D 必须最后、不要引号）
MolecuLens-2.19.0-win64-Setup.exe /S /D=D:\Apps\MolecuLens
```

## 三、免安装版

`MolecuLens-<版本>-win64-portable.zip` 解压即用：`moleculens_app.exe` 与
`moleculens-cli.exe` 在同一目录，`font/`、`data/` 与 exe 同级（程序按 exe 所在目录
解析字体与示例数据）。适合放在 U 盘或没有安装权限的机器。
用户偏好仍写入 `%APPDATA%\MolecuLens\settings.json`。

## 四、卸载

* 设置 → 应用 → 已安装的应用 → MolecuLens → 卸载；或
* 开始菜单 → MolecuLens → 卸载 MolecuLens；或
* 静默卸载：`"%LOCALAPPDATA%\Programs\MolecuLens\uninstall.exe" /S`。

卸载会删除程序文件、快捷方式与注册表项，**保留** `%APPDATA%\MolecuLens\settings.json`
（主题、布局、播放节奏等偏好），重装后自动沿用。想彻底清理可手动删除该目录。

## 五、从源码重新打包（维护者）

```powershell
powershell -ExecutionPolicy Bypass -File tools\package_release.ps1 -Version 2.19.0
```

一条命令完成「配置 → 编译 → 安装目录 → NSIS 安装程序 → 免安装 ZIP → SHA256」，
产物在 `dist/`。需要 CMake ≥ 3.21、Ninja、MSVC 2022 与 vcpkg 依赖（首次请先
`vcpkg install`），以及 NSIS 3（含 `nsProcessW` 插件）。

原理与细节见 [`installer/README.md`](../installer/README.md)：

* `cmake/packaging.cmake` —— `install()` 规则（可执行文件、vcpkg DLL、app-local CRT、
  字体、示例数据、许可）与 CPack ZIP；
* `installer/moleculens.nsi` —— 安装程序（MUI2 中文向导、组件、快捷方式、HKCU 卸载项、
  运行中进程检测）；
* `tools/package_release.ps1` —— 工具链探测与全流程编排。

## 六、发布检查清单

1. `tools\package_release.ps1` 全程无 *错误*，`dist/` 出现 Setup.exe、portable.zip、SHA256SUMS.txt；
2. 在干净的 Windows 10/11 x64 上静默安装 → 启动 GUI（Vulkan 画面正常）→
   `moleculens-cli.exe info data\EPI.pdb` 有输出 → 静默卸载后目录与注册表项清空；
3. 记录 `SHA256SUMS.txt` 的内容到发布页；
4. 版本号只改 `-Version` 一处（安装包文件名、注册表 `DisplayVersion`、安装器标题同步）。
