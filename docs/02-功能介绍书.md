## 1 产品定位

### 1.1 一句话定位

MolecuLens v2 是一个**本地运行的分子可视化与论文出图工作台**：读入结构文件（PDB / GRO / SDF / CUBE），用 14 种表示样式与 23 套材质在 Vulkan 视口里实时显示，把 Gaussian / Multiwfn 生成的电子密度与静电势 cube 映射成可发表的彩色表面，最后导出为图片。

它不做量化计算，也不替代 Multiwfn：**计算在你的既有流程里完成，MolecuLens 负责「看得对、调得快、出得来图」**。

**标识（Logo）**：深蓝→青的圆角方块里，一枚白色**透镜环**包住一个**三原子分子**——透镜代表「观察 / 成像」，分子代表被观察的对象，两者合一就是 MolecuLens 的名字。程序 exe 图标、标题栏左侧的小标识与本文插图完全同源（矢量绘制，任意 DPI 都清晰）。

![应用标识：透镜环 + 三原子分子（1024 px 母版）](figs_v2/logo.png)

横版字标用于文档封面、答辩 PPT 与项目材料：

![横版字标：标识 + MolecuLens + 分子可视化工作台 · AURORA](figs_v2/wordmark.png)

### 1.2 为什么有 v2（Aurora）

v1 采用 ImGui docking 布局，面板可任意停靠，由此带来三个困扰：

1. **空白停靠区**：首启右侧是一块空窗，新手不知从哪开始；
2. **出图路径长**：「样式 → 材质 → 表面 → 色标 → 背景」散落在四个浮动窗口；
3. **风格不统一**：各面板字号与配色来自不同时期。

v2 因此改为 **Multiwfn 式的固定工作台**（见下图）：

| 区域 | 尺寸（1280×800 基线） | 作用 |
| --- | --- | --- |
| 标题栏 | 36 px，自绘 | `MolecuLens v2 · Aurora` 与文件名、窗口按钮 |
| 菜单栏 | 36 px | 文件 / 视图 / 样式 / 帮助 |
| 文件栏 | 44 px | 只读路径框 + 打开 / 保存 / 导出 PNG / 语言 / 主题 / 设置 |
| 左导航 | 92 px（收起后 **46 px**） | 10 个模块入口（矢量图标 + 文字，按钮高 62 px）；顶部 ‹‹/›› 或 `Ctrl+B` 可收起，只剩图标 + 悬停提示 |
| 中央视口 | 自适应 | 3D 场景、左上悬浮工具条、右下 ESP 色标与极值标注；左导航收起后自动变宽 |
| 右检查器 | **380 px**（260–480 可调） | 当前模块的全部参数；宽度在「设置 → 外观」用滑杆调整 |
| 快捷条 | 46 px | 一键风格 `sob-art` / 清空样式 ｜ 隐藏氢 / 网格质量（1.0 / 0.5 / 0.25 / 0.15 Å）/ 背景（取色面板）/ 光追预览 / 导出 PNG；右端「N 个表示」 |
| 状态栏 | 26 px | FPS、原子数、分子数、帧号、渲染后端 |

![图 1-1 工作台总览（浅色 Aurora 主题）](figs_v2/overview.png)

### 1.3 设计原则

| 原则 | 具体做法 |
| --- | --- |
| **结构优先** | 布局固定不可停靠；左导航可在 92 / 46 px 两档间收起（`Ctrl+B`），常用操作只有一个入口，不存在「窗口找不到」 |
| **一次点击见结果** | 风格、网格质量、背景、导出挤在一行；一键 `sob-art` 覆盖八成出图需求 |
| **数据不出本机** | 无账号、无上传、无遥测；渲染与导出全在本地 |
| **诚实的能力边界** | 未实现的样式与分析项**置灰并说明**，不隐藏、不假装可用 |
| **默认即良好** | 浅色 Aurora 主题 + 球棍 + MSAA 4×，打开即读 |

## 2 目标用户与典型场景

### 2.1 用户画像

| 用户 | 关注点 | 在 MolecuLens 中的典型任务 |
| --- | --- | --- |
| 计算化学研究生 | 出图质量、色标是否规范、能否进论文 | 打开优化后的结构 → 套 sob-art（或「样式 → IQmol」）→ ESP 映射 → 导出 PNG |
| 结构生物学研究者 | 蛋白整体形态、通道/口袋 | 打开 PDB → Cartoon / NewCartoon → 加分子表面 → 取景 |
| 高校教师 | 课堂演示要快、能讲清概念 | 按 `1` 套 sob-art、`H` 隐藏氢、`Space` 播放轨迹 |
| 材料/溶剂化方向 | 几万原子的体系也要能动 | QuickSurf 快速密度表面 + 「整体系合并表面」 |
| 项目评审 / 软著材料 | 界面稳定、功能可复现 | 固定五区布局截图，同一操作用例可重复 |

### 2.2 三个典型场景

**场景 A（论文 ESP 图）**：Gaussian 优化 → Multiwfn 导出 `density.cub` / `totesp.cub` → 打开结构、创建 ESP 表示、指定两个 cube；待表面生成完成（界面左下「表面生成中…」消失）即得到按 0.001 a.u. 等值面裁切、±45 kcal/mol 着色的静电势表面，导出 PNG 时色标与极值标注会一并写入图内，无需后期拼图。

**场景 B（课堂演示）**：按 `1` 切 sob-art，隐藏氢，轨道模块载入 MO 的 cube，阈值调到 0.02，转动两圈即可讲清节面。

**场景 C（轨迹检查）**：打开 `md.gro`，导入 `md.xtc`，滑块跳到第 300 帧，设 In/Out 只循环关键片段，0.1× 慢放观察氢键网络。

## 4 功能模块详解

左导航固定 **10 个模块**（位置固定，不支持拖拽/停靠），每个模块 = 左导航的一项 + 右检查器的一页。导航按钮是**图标 + 文字**的竖排，选中项为浅蓝底 + 左侧竖条。**左栏可收起**：点左导航顶部的 ‹‹ / ›› 按钮、按 `Ctrl+B`，或走菜单「视图 → 收起工作区 / 展开工作区」，宽度在 **92 px ↔ 46 px** 之间切换——收起后只剩 10 个矢量图标（悬停才显示模块名），「工作区」小标题与底部版本号一起隐藏，腾出的宽度**自动给视口**（不需要拖拽或重启）。检查器默认 **380 px**，可在 **260–480 px** 之间调整——入口是「设置 → 外观 → 宽度」滑杆（不是拖拽边缘），目的是默认把宽度让给视口。

### 4.1 分子（场景与体系）

**解决什么问题**：一次打开多个结构时，需要知道「场景里有什么、谁可见、谁该删」。

**怎么用**

1. `Ctrl+O` 打开结构文件（可重复打开多个，各自成为独立的「分子」）——默认过滤器覆盖 PDB（`.pdb`/`.ent`）、GRO（`.gro`）、SDF（`.sdf`/`.mol`）、CUBE（`.cube`/`.cub`）与 `.mlscene` 场景，另有「所有文件 (*.*)」；扩展名清单由解析器注册表生成，新增格式不需要改界面；
2. 在「分子」列表勾选控制可见性，点「隐藏氢」只看骨架；
3. 点「取景全部」（或按 `F`）让可见内容填满视口。

**参数**

| 控件 | 取值 | 默认 | 说明 |
| --- | --- | --- | --- |
| 打开结构文件 / 导入轨迹 | 按钮 | — | 与文件栏、文件菜单入口等价 |
| 保存场景 | 对话框 | 链接式（推荐） | 先选轨迹存储方式：**链接式**只存路径+指纹（文件小，源轨迹移动后需重新指定）；**嵌入式**把轨迹帧写进 `.mlscene`（可单文件分发，体积随帧数×原子数增长，≥200 MB 会提示改用链接式）。`Ctrl+S` 与文件栏「保存场景」、菜单「文件 → 保存场景…」都先弹此框，选择记入 `settings.json` |
| 分子 · 可见 | 勾选 | 真 | 取消勾选即隐藏，不卸载数据 |
| 分子 · 删除 | 按钮 | — | 从场景移除该分子（即时生效，无撤销） |
| 体系 · 可见 | 勾选 | 真 | 体系是分子的逻辑分组，用于合并表面/实例 |
| 体系 · 删除 | 按钮 | — | 移除分组，成员分子保留 |
| 隐藏氢 | 开关 | 关 | 对所有分子生效：把每条表示的选择改成 `not element H`，关掉即还原 |
| 取景全部 / 重置视角 | 按钮 | — | 等价于 `F` / `R` |

**限制与提示**

> 提示：v2 检查器**不提供**体系的新建、重命名与跨组移交——v1 的分子列表浮窗曾有这些入口，但旧面板在 v2 中**不再实例化**（代码只保留在 `#if 0` 里）；删除按索引即时生效、不可撤销，动手前先确认当前选中对象。

### 4.2 显示（样式、材质与选择表达式）

**解决什么问题**：讲「键长」要看棍模型，讲「口袋」要看表面，投稿要「好看」。样式与材质是出图的第一层。

**怎么用**

1. 打开结构后自动选中第一个表示；没有表示时点「创建球棍表示」；
2. 「绘图样式」选类型，「配色」选着色依据；
3. 调「原子半径」「键半径」控制疏密，「不透明度」做叠加；
4. 只改一部分时在「选择表达式」写作用域（如 `resid 1-20`、`within 4 of element Fe`）；
5. 想脱离预设的「死板」时展开 **「材质微调」**：三个取色器（环境色 / 漫反射色 / 高光色）加三条滑杆（光泽度 / 金属度 / 粗糙度），「恢复预设材质」一键回到当前预设。

**参数**

| 参数 | 取值 | 默认 | 说明 |
| --- | --- | --- | --- |
| 表示管理 | 目标表示下拉 + 新建 / 删除 / 可见 | 加载即有一条 `ballstick` | 表示是**场景级**的：每条表示作用于整个场景，不按分子分配 |
| 绘图样式 | 14 种：线框、棍状、球棍、空间填充、甘草棍、范德华球、快速表面、分子表面、ESP 映射表面、管状、卡通、改进卡通、丝带、**平板（辅基）** | 球棍 | 表面类样式与表面模块共享网格参数；平板按「链+残基」分组、每块 ≥3 原子，见下方提示 |
| 配色 | 元素 CPK / 按链 / 按残基 / 按 BFactor / 统一色 | 元素 CPK | 「统一色」用于剪影或叠加对比 |
| 材质 | 23 套预设（默认 Opaque，另有 Transparent、BrushedMetal 等）+「自定义」 | Opaque | 手改任一材质参数即变为「自定义」 |
| 材质微调 | 可折叠组：环境色 / 漫反射色 / 高光色取色器 + 光泽度 1–256、金属度 0–1、粗糙度 0–1 | 折叠 | 任一改动即写回该表示并切到「自定义」；组内「恢复预设材质」回退 |
| 原子半径 | 0.05 – 5.00 | 1.00 | 与样式球半径相乘；范德华球样式不受此缩放 |
| 键半径 | 0.05 – 5.00 | 1.00 | 键为圆柱，半径 = 0.15 × 原子半径 × 键半径 |
| 不透明度 | 0.05 – 1.00 | 1.00 | 小于 1 时进入透明通道绘制 |
| 选择表达式 | 空 = 全部 | 空 | 支持元素、残基区间、`within N of …`；解析失败不应用 |

**限制与提示**

> 提示：键圆柱按勾股关系缩进端面（`d = √(R² − r²)`，封顶键长 40%），极小半径下也不会出现两球间的空隙；体积类样式（表面/快速表面/ESP 表面）不投阴影，避免等值面自阴影造成「脏边」。

> 提示：**平板（辅基）** 把每个「链 + 残基」画成一块彩色方片——**≥3 个原子**才生成，朝向取原子云协方差的主成分轴，长/宽按跨度 ×1.05、厚度 0.08–0.30 Å；颜色取组内**第一个原子**，所以要区分不同辅基请用「按残基 / 按链」配色，并用选择表达式只选辅基（如 `resname CHL`）。适合示意图里把叶绿素这类辅基画成小方片，而不是球棍。

### 4.3 表面

**解决什么问题**：让分子「有体积感」，也是 ESP 映射的几何基础。

**怎么用**

1. 点「创建快速表面」（高斯密度等值面，快）或「创建分子表面」（按原子半径的滚球近似）；
2. 选「网格质量」：低 / 中 / 高 / 超高（1.00 / 0.50 / 0.25 / 0.15 Å）；
3. 调「等值面阈值」决定胖瘦；体系内多分子共享一张表面时打开「整体系合并表面」。

**参数**

| 控件 | 取值 | 默认 | 说明 |
| --- | --- | --- | --- |
| 网格质量 | 低 1.00 / 中 0.50 / 高 0.25 / 超高 0.15 Å，或「自定义」 | 中（0.50） | 越小越细腻，三角面数近似按 1/h² 增长 |
| 等值面阈值 | 0.05 – 2.00 | 0.50 | 高斯密度阈值；越小越外扩 |
| 整体系合并表面 | 开关 | 关（体系实例数 > 32 时切到表面样式会自动开启） | 把整个体系的分子并入一张表面，见第 6 章 |
| 不透明度 | 0.05 – 1.00 | 1.00 | 半透明只绘正面（背面剔除），无 OIT |
| 可见 | 勾选 | 真 | 隐藏但保留计算结果 |

**限制与提示**

> 提示：表面生成是**异步**的，未完成时视口左下显示「表面生成中…」，场景沿用上一帧命令，不卡界面；表面样式会覆盖分子外观，想同时看骨架就把不透明度降到 0.3–0.5。

### 4.4 静电势（ESP）

**解决什么问题**：把「电子密度形状」与「静电势数值」合成一张图，是判断亲电/亲核位点最直观的表达。

**怎么用**

1. 准备**两个 cube**：密度 cube（几何）与静电势 cube（颜色）；
2. 「密度 cube」点「浏览…」选电子密度文件——两个路径都要手动指定，**不会**自动沿用当前打开的文件；
3. 「静电势 cube」点「浏览…」选 Multiwfn 生成的电位文件；
4. 调「密度阈值」（默认 0.001 a.u.）与「不透明度」（默认 1.00，建议降到 0.6–0.85 以便看见内部骨架）；
5. 需固定量程时关闭「自动范围」手填上下限，再选配色方案与是否「翻转色标」。

**参数**

| 控件 | 取值 | 默认 | 说明 |
| --- | --- | --- | --- |
| 密度阈值（iso） | 0.0005 – 0.02 a.u. | **0.001** | 0.001 ≈ vdW 面；0.0005 更外扩；0.005 更贴身 |
| 密度 cube（几何） | 文件 | 未选择 | 必填；决定等值面形状 |
| 静电势 cube（颜色） | 文件 | 未选择 | 必填；与密度 cube 必须同网格 |
| 自动范围 | 开关 | 开 | 发散型取 ±99.5 分位 \|V\|；退化时下限 ±1 kcal/mol |
| 下限 / 上限 | −300 – +300 kcal/mol | −45 / +45 | 仅「自动范围」关闭时生效；上限会被抬到 ≥ 下限 + 1 |
| 配色方案 | Rwb / Bwr / Coolwarm / Turbo / Viridis / Jet / Reference | Rwb | Reference 为黄→绿→青→蓝→紫，近 GXNU MolStudio |
| 翻转色标 | 开关 | 关 | 交换正负端颜色 |
| 不透明度 | 0.05 – 1.00 | 1.00 | 建议 0.6–0.85，半透明更利于看清内部骨架 |
| 极值点标注 | 无独立开关 | 自动 | 与色标条一同显示在视口右下；每侧最多 8 个，1.2 Å 非极大抑制去重 |

**限制与提示**

> 提示：MolecuLens **不内建量化计算**，cube 须由 Gaussian / Multiwfn / ORCA 等生成；单位换算在内部完成（Bohr → Å，Hartree → kcal/mol ×627.509474），无需预先换算。Multiwfn 菜单路径见[《使用说明》4.2](03-使用说明.md#42-esp-映射表面)。

> 提示：极值点为「顶点邻域局部极大/极小 + 1.2 Å 非极大抑制」，与 Multiwfn 的 `surfanalysis.pdb` **可能有位置与数量差异**，投稿前建议人工核对。

### 4.5 轨道（体数据等值面）

**解决什么问题**：快速看分子轨道/自旋密度/差分密度的**空间形状**，用于讲节面与相位。

**怎么用**

1. 打开（或拖入）一个 `.cube` 文件，模块显示网格维度、数值范围、原子数，用于核对；
2. 拖动「等值面阈值」（默认 0.02）直到形状清晰；
3. 点「生成等值面表示」：同一份 cube 兼作几何与颜色来源，正负值按数值大小着色。

**参数**

| 控件 | 取值 | 默认 | 说明 |
| --- | --- | --- | --- |
| 等值面阈值 | 0.0005 – 0.500 | 0.02 | 绝对阈值（与 cube 内数值同单位），不是相对最大值；太小会出现碎片 |
| 网格 / 数值范围 / 原子数 | 只读 | — | 用于核对载入的 cube |
| 生成等值面 | 按钮 | — | 生成一个 ESP 表面表示 |

**限制与提示**

> 提示：当前是**通用体数据等值面**，未接入 fchk/MO 解析，因而不区分 ± 相位配色、不能叠加双等值面、不显示节面（均在路线图）。

### 4.6 轨迹

**解决什么问题**：MD 或优化过程要看「怎么动」，而不只是「最后长什么样」。

**怎么用**

1. 先打开结构文件（提供原子与拓扑）；
2. 「导入轨迹」选择 `.dcd` / `.xtc` / `.trr`（原子数必须与结构一致）；

4. 设「播放速度」与「循环播放」；只看片段时填「帧范围」起/止（止 = 0 表示末帧）。

**参数**

| 控件 | 取值 | 默认 | 说明 |
| --- | --- | --- | --- |
| 帧滑块 | 1 – 总帧数 | 首帧 | 拖动即时更新坐标 |
| 播放速度 | 0.1 – 10.0× | 1.0× | 与帧率解耦，按实测时间步推进 |
| 循环播放 | 开关 | 开 | 到末帧回到首帧 |
| 帧范围 In / Out | 整数，Out = 0 表示末帧 | 0 / 0 | 只在该区间循环 |

**限制与提示**

> 提示：仅支持播放 DCD / XTC / TRR，不做格式转换、不写出轨迹文件；当前也**没有动画/视频文件导出**（PNG 序列、APNG、GIF、MP4/WebM 均在路线图），出动态图请用逐帧导出或外部录屏。没有帧数据时模块会显示「当前场景没有帧数据。导入 DCD/XTC/TRR 轨迹后可在此播放。」并给出「导入轨迹」按钮。

### 4.10 标注（示意图：水盒 / 标签 / 箭头 / 水印）

**解决什么问题**：把「一张好看的分子图」变成「一张能讲清结构的示意图」——标出周期盒、给分子命名、画箭头（含光子入射的波浪箭头）、加半透明水印；这些标注**随 PNG 一起栅格化**，不需要后期再拼图。

**怎么用**（左导航「标注」）

1. **水盒 / 周期盒**：打开「显示水盒」；来源二选一——**跟随轨迹盒**（取轨迹首帧的 9 分量 box，支持三斜）或**手动指定**（盒中心 XYZ + 半长 XYZ，单位 Å）；手动模式可点「适配场景」按当前包围盒 ±5% 自动填；再调盒线颜色与线宽（0.8–4.0 px）。纯 PDB 没有 box，必须手动。
2. **文字标签**：输入文字，锚点三选一（分子序号 / 世界坐标 XYZ / 视图中心），设颜色与字号（9–48 px），点「添加标签」；列表里可改可见性、字号、颜色或删除；「为前 N 个分子命名」按分子名批量生成（大体系建议 < 50）。
3. **箭头**：端点二选一（分子序号 / 坐标）；样式「普通箭头」或「波浪（光）」（示意光子入射）；线宽 1–8、箭头大小 0.4–2.5、可勾双头、可选颜色；列表可删/隐藏。
4. **水印**：文字 + 颜色/透明度（RGBA）+ 字号（图高 3%–30%）+ 锚点四选（右下 / 左下 / 居中 / 右上）。
5. **一键风格**：「应用示意图风格」= 黑底 + 强轮廓（`outline=0.80`、`wrap=0.55`）+ 平光材质 + 关阴影，并自动打开水盒与水印；「应用出版风格」= 黑底 + 平光 + 弱轮廓。

**参数**

| 控件 | 取值 | 默认 | 说明 |
| --- | --- | --- | --- |
| 水盒来源 | 跟随轨迹盒 / 手动指定 | 跟随轨迹盒 | 轨迹首帧需带 box；纯 PDB 手动 |
| 盒中心 / 盒半长 | XYZ，Å | 0 / 20 | 手动模式；「适配场景」按包围盒 ±5% 填 |
| 盒线颜色 / 线宽 | RGBA / 0.8–4.0 px | 淡蓝 / 1.4 px | 导出按图高同比放大 |
| 标签锚点 | 分子序号 / 坐标 / 视图中心 | 分子序号 | — |
| 标签字号 | 9–48 px | 18 px | 导出同比放大 |
| 箭头样式 | 普通 / 波浪（光） | 普通 | 波浪用于光子入射示意 |
| 箭头线宽 / 大小 | 1–8 / 0.4–2.5 | 2.2 / 1.0 | 可勾双头 |
| 水印大小 / 锚点 | 图高 3%–30% / 右下·左下·居中·右上 | 10% / 右下 | RGBA 透明度可调 |

**限制与提示**

> 提示：标注随 PNG **一并栅格化（8-bit 路径）**，并按图像高度等比放大（900 px 基准）；**16-bit 与 CPU 光追导出暂不含标注**；勾选「透明背景」时标注会跳过（与 ESP 色标同一取舍）。

> 提示：标注**随场景保存**——写入 `.mlscene` 元数据的可选键 `annotations`（空标注不写键，旧文件缺键 = 空），重开场景会提示「已载入场景标注（水盒/标签/箭头/水印）」。水盒按**原始几何**保存（`origin[3]` + `axes[9]`，三斜也精确），载入后显示为「手动指定」；一旦改中心/半长就切回轴对齐。

> 提示：示意图里的辅基（叶绿素等）建议用「**平板（辅基）**」表示 + 「按残基 / 按链」配色，再叠一层卡通画骨架（见 §4.2）；平板按残基分组、每块需 ≥3 个原子。

## 5 一键样式

> v2.1 起快捷条只保留 `sob-art` 与「清空样式」；`IBOview` / `HoukMol` / `IQmol` 三套风格移到菜单「样式」下（快捷条腾出的位置改放网格质量、光追预览等常用功能）。

快捷条的 `sob-art` **整体替换**当前所有表示与背景，等于「给这张图定调」；再点不叠加，改任何参数后胶囊熄灭即自定义状态。另外三套风格从「样式」菜单进入，行为完全相同。

| 预设 | 视觉目标 | 实际参数组合（代码中生效的部分） | 建议用途 |
| --- | --- | --- | --- |
| **sob-art** | 深色学术海报风，颜色饱和、背景压暗突出主体 | 背景 (0.09, 0.11, 0.16)；球棍 + 元素 CPK + Opaque 材质 | 组会/答辩 PPT 深色页、屏幕展示 |
| **IBOview** | 白底半透明「玻璃壳」，内部骨架隐约可见 | 背景纯白；球棍 + 快速表面（系统表面，等值面 0.35，不透明度 0.35，Transparent 材质） | 口袋/通道、需要看内外的结构 |
| **HoukMol** | 深底粗棍，强调骨架拓扑 | 背景 (0.05, 0.06, 0.09)；棍模型 + 元素 CPK | 有机反应机理、构象对比 |
| **IQmol** | 白底高光泽，接近期刊插图的「上过漆」质感 | 背景纯白；球棍 + 元素 CPK + BrushedMetal 材质（各向异性高光） | 论文正文图、需要干净白底 |
| **清空样式** | 回到出厂 | 删除全部表示并重建默认球棍，背景不动 | 试错后复位 |

> 提示：四个预设（`sob-art` 在快捷条，其余三套在「样式」菜单）**只改表示与背景**，不动相机与色标；想「预设 + 自定义」就先点预设再微调（如把后加表面换成 ESP 表面），此时胶囊熄灭属正常。快捷条的「背景」胶囊只是打开取色面板，**不重建表示**，用来单独换底色。

## 7 差异化价值

1. **固定工作台 × 中文优先**：Multiwfn 的参数密度 + 现代 GUI 的布局秩序，评审与课堂都不必先学「窗口管理」。
2. **ESP 是一等公民**：不是插件或后处理，而是与密度/势两个 cube 直连的原生表示，色标与极值随视口呈现并写入导出的 PNG。
3. **一键定调**：四个预设把样式、材质、背景、表面打包，三秒从「能动」到「能投」。
4. **可复现、可分发**：`.mlscene` 保存结构、坐标与表示参数，材质名是稳定键，同一张图可原样重建；轨迹可选**链接式**（只存路径，文件小）或**嵌入式**（帧写进单文件，可直接发给别人）。
5. **诚实**：绘图样式只列本引擎真实支持的 14 种，不拿 VMD 的 27 项清单凑数；尚未接入的分析项直接置灰并注明原因。

---

## 8 已知限制

以下限制**在当前版本确实存在**，请勿在宣传材料中回避：

1. **导出只有单帧 PNG**：工作台导出对话框可设 1×/2×/4× 输出像素与透明背景，写盘走视口离屏渲染；暂无 SVG / PDF / TIFF，也不导出动画视频。
2. **ESP / 轨道依赖外部 cube**：不内建量化计算，不解析 fchk。
3. **轨道无 ± 相位配色**：按数值着色，不能像 IQmol 那样红/蓝区分。
4. **体系管理不完整**：v2 只能切换可见性与删除，新建 / 重命名 / 跨组移交未提供（v1 浮窗已不再实例化）。
5. **轨迹格式有限**：仅 DCD / XTC / TRR，无多帧 XYZ、无写出、无视频导出。
6. **表面为 CPU Marching Cubes**：超大体系靠异步与「整体系合并表面」掩盖延迟，并行/缓存优化在路线图。
7. **半透明无 OIT**：层叠表面有排序瑕疵，不绘背面。
8. **极值点与 Multiwfn 有差异**：算法不同（顶点邻域 + 1.2 Å NMS），数量/位置可能不同。
9. **分析仅统计**：电荷、键级、NBO、IGMH 未接入。
10. **脚本能力有限**：无 Python 绑定、无插件 ABI；命令行只有 `render` / `convert` 两个子命令。
11. **界面状态不跨会话记忆**：左导航收起态、当前页与检查器宽度都是运行期状态，重启回到「展开 + 首个模块 + 380 px」。需要固定窄栏时每次启动按一次 `Ctrl+B`。
12. **嵌入式只覆盖轨迹帧**：`.mlscene` 的「嵌入式」把轨迹坐标打包进单文件，但 ESP / 轨道引用的 cube 仍是外部路径，不会被一起打包；单文件分发时这些文件仍需另行带上。命令行保存也仍按链接式（本轮只做 GUI）。
13. **标注的导出有限制**：水盒 / 标签 / 箭头 / 水印已随 `.mlscene` 保存（可选键 `annotations`，旧文件缺键为空）；但 PNG 导出只覆盖 8-bit 路径（16-bit 与 CPU 光追导出不含标注），透明背景下跳过。

## 9 路线图

与《01 软件架构书》的 P0–P3 阶段划分一致。**以下均为规划，不是现有功能。**

| 阶段 | 内容 | 验收口径 | 状态 |
| --- | --- | --- | --- |
| **P0** | 四类可重放基准（解析 / 表面 / 帧时 / 命令流）与导出基准数据 | 导出 4K PNG 与视口一致；基准可在 CI 复跑 | 导出已交付，基准待补测 |
| **P1** | 表面生成性能优化（增量/缓存/并行，方案待定）；体系管理 UI（新建/重命名/移交）；轨迹格式扩展（XYZ 读、DCD 写）；动画导出（ffmpeg 管道，MP4/WebM） | 10 万原子体系表面 < 1 s；轨迹可换格式另存 | 规划中 |
| **P1** | 轨道增强：fchk/MO 解析、双等值面叠加、± 相位配色、节面显示 | 载入 fchk 可直接选 MO 序号 | 规划中 |
| **P2** | 分析后端：对接 Multiwfn 输出（电荷、键级、NBO E2、IGMH/IRI）并可视化 | 一个分子从 cube 到分析图不离开本软件 | 规划中 |
| **P2** | Python 脚本（pybind11 已在依赖清单中，可选开）+ 命令行增强（现有 `moleculens-cli render/convert` 之外的新子命令与批处理脚本） | 脚本可批量出图 | 规划中 |
| **P3** | 插件 ABI、跨平台（Linux/macOS 后端） | 第三方可写渲染/分析插件 | 规划中 |

> 提示：顺序是「先让图能存下来（P0），再让大体系能动（P1），最后让数据闭环（P2/P3）」；任何一期都不改 `.mlscene` 的稳定键名。
