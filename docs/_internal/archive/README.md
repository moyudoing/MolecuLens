## 不要重做（这些结论已被验证或证伪）

1. **「surface 是每个分子单独细分的球面，可换共享单位球 + 逐实例变换」——判断错误。**
   911,096 个三角形是整体系 Marching Cubes 网格（约 141 三角形/原子），不存在可复用的单位球。
   要减三角形只能降网格精度或做网格简化，两者都会改变渲染结果。
2. **逐实例 QuickSurf 网格缓存**：能拿到 Debug 2.1×（11867→5650 ms），但局部栅格的 MC 相位与
   世界栅格不同，像素差 21.9%，已回退。是否接受这笔交易仍未决（见 `ISSUES` I-17）。
3. **BVH 调参**：叶子 4→16、并行阈值 8192→2048、线程预算 8→16 都实测更慢，已回退；瓶颈是内存带宽。
4. **视锥剔除**在 6.4k 原子场景上无可测收益（放大后受片元填充限制反而更慢），但实现正确、逐位一致，
   保留给 10⁵ 原子级体系。
5. **线框配色 + 颜色空间**：半键拆分、`AtomName` 默认配色、Chain/Residue 混入 `instanceIndex`
   扰动、`colorForAtom` 返回线性色（修 sRGB 二次编码）全部已落地，不要再从头查这三因。
6. **构建与验收口径**：`MSB3073` 是 vcpkg post-build 噪声；判定成功看链接行 `-> ...exe`。
   渲染路径改动前先拍基线 PNG md5，改完必须逐位一致。
7. **「播放速度 = 物理 dt」**（v2.12 修复）：轨迹 dt 是物理步长（10 ps），拿它当实时
   间隔会变成 10 秒一帧。实时速度只由 `playbackFps × speed` 决定（见 CHANGELOG v2.12 §1）。
8. **在时间轴子窗口之后取 `GetItemRect()` 当视口矩形**（v2.12 修复）：`GetItemRect()`
   返回最后一个控件；导入轨迹后相机输入区错位、拖拽/滚轮失效（CHANGELOG §2）。
9. **逐实例 `globalAtomBase()`**（v2.12 修复）：O(i) 累加在帧切/渲染循环里退化为 O(n²)；
   已改为前缀和/递增基址，不要写回（CHANGELOG §1）。
