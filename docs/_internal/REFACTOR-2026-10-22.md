## 2. 问题清单（按优先级）

### P0 — 正确性 / 一致性（必须先做）

| # | 问题 | 证据 | 影响 |
|---|---|---|---|
| P0-1 | **坐标应用有三套实现**：`SceneStructure::applyTrajectoryFrame`（GUI 播放/导出）、CLI `applySystemFrameToScene`（本次新增）、GUI 动画导出沿用前者但无时间轴展开 | 三处在 PBC 补齐、分子回盒、实例变换、时间轴连续化上语义不同 | 同一轨迹在 GUI 播放 / GUI 导出 / CLI 导出观感不一致；动画"闪烁"根因之一 |
| P0-2 | **命令流坐标重放不可靠**：整体系逐帧换坐标时 replay 会错位，CLI 动画被迫 `setDirty(DIRTY_INSTANCE)` 强制整条重建 | `render_cmd.cpp` 动画分支注释；CLI 动画 ~6–7 fps | 导出慢 5–10×；GUI 逐帧重放同样存在风险 |
| P0-3 | **动画采样语义不清**：`md.xtc` 相邻帧平均原子位移实测 ~5 Å，与 `dt=10 ps` 的水扩散不符 | 本次 `--anim` 自检（interp=4 时每渲染帧 1.23 Å） | 时间轴展开/插值只是显示层补丁；"物理时间 → 播放率"没有单一模型 |
| P0-4 | **GUI 动画导出同步阻塞主线程**，无进度、无插值 | `ExportImgTool::startAnimationExport` 注释"正确性优先" | 大轨迹导出期间界面无响应，且 GUI 无法得到 CLI 的平滑效果 |

## 3. 改造方案

### 阶段 A（1–2 天）：坐标语义统一 + 动画正确性

1. **A1 单一坐标入口**
   - 在 `entity::SceneStructure` 增加 `applyFrame(const FrameView&)`：
     `FrameView { frameIndex, mode = DisplayWrapped | Continuous, interpolationT }`。
   - 内部封装：实例切片 → 分子内 PBC 补齐 → 分子整体回盒（Display）或连续推进（Continuous）→ 实例变换。
   - GUI 播放、GUI 导出、CLI 全部改走该入口；删除 CLI 的重复实现。
2. **A2 动画帧流**
   - 新增 `engine::anim::FrameStream`：负责 连续缓冲（时间轴展开）→ 插值 → 输出 `DisplayWrapped` 坐标，
     GUI/CLI 共用；`--anim-interp` 与 GUI 插值共用同一参数。
3. **A3 replay 一致性**
   - 新增单测：同一帧分别走"坐标重放"和"整条重建"，PNG 逐像素一致；
   - 修复后移除 CLI 的强制重建，恢复增量性能。
4. **A4 动画单测**
   - 固定 20 帧小轨迹：帧文件名顺序、`interp=2` 时相邻帧位移减半、ffmpeg 缺失时返回明确错误；
   - ffmpeg 参数拼装单测（可用假二进制 stub）。

**验收**：同一轨迹同一帧，GUI 导出与 CLI 导出 PNG 一致；动画单测全过；CLI 动画 ≥ 15 fps（800×600）。

### 阶段 B（3–5 天）：拆分与后台化

1. `render_cmd.cpp` 拆 4 文件；`modules.cpp` 拆 4–6 文件；`workbench.cpp`、`mol_scene.cpp` 各拆 3 文件。
2. GUI 动画导出放后台：主线程逐帧提交 + 进度条（复用图像导出的 `exportThread_` 模式，但坐标写回在主线程）。
3. CMake 字体 helper；i18n 补录到 0；`AddText` 字形清单移到 `app/i18n/glyphs.h`。

**验收**：单文件 < 800 行；目录粒度检查通过；构建 0 警告；导出期间界面响应、有进度。

### 阶段 C（1–2 周）：功能与性能

- 自适应 LOD（ROADMAP §2.1）；
- DFT：MO 等值面 + 能级图（ROADMAP §2.2）；
- 动画增强：相机轨道源、透明/体积、导出预设（ROADMAP 补充项）。

## 4. 风险与不做的事

1. **统一坐标语义**会同时改动播放与导出，回归门槛必须是"同帧逐像素一致"，不能只看"看起来对"。
2. **拆分大文件**易引入 include/静态初始化问题：每个文件单独提交，构建+测试通过再拆下一个。
3. **采样语义**修正可能改变现有动画观感：保留 `--anim-fps` / `--anim-interp` 兼容，不强制切换。
4. **不做**：为了拆分而改行为；为通过测试而放宽断言；在没有逐位基线的情况下改渲染路径。
